# Wortschwipe

A single-page, no-backend web game that teaches German noun genders (der/die/das) using a Tinder-style swipe interface.

- Swipe left = **der** (blue), right = **die** (pink), up = **das** (gold)
- Drag/touch swiping, keyboard arrows, and tap buttons all work
- ~60 common German nouns with English meanings
- Streak counter and session score (in-memory only, resets on refresh)

Everything lives in `index.html` — inline CSS/JS, no build step, no dependencies. Open it directly in a browser or deploy it as a static site.
